# ProjectShelf – A Centralized Platform for Managing and Sharing Academic Projects

## About the Project
ProjectShelf is a web-based platform that helps students manage, discover, and share academic projects in one place.

## Features
- Student registration and login
- Personalized student dashboard
- Project upload with GitHub links and project files
- Project details and technology information
- My Projects page
- Search and filter academic projects

## Technologies Used
- Frontend: HTML, CSS, JavaScript
- Backend: Python and Flask
- Database: SQLite
- Version Control: GitHub

## Installation and Setup

1. Install Python.
2. Clone or download this repository.
3. Open the project folder in a terminal.
4. Install the required packages:

   `pip install -r requirements.txt`

5. Run the application:

   `python app.py`

6. Open `http://127.0.0.1:5000` in your browser.
